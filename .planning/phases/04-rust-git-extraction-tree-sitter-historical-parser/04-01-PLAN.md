<context>
Phase 4 Plan 01 implements the first fundamental layer of the Git extraction engine: walking commits and calculating diffs. Following decisions D-01 through D-04 and the architectural research, `gitctx-core` needs a robust, zero-panic wrapper over `libgit2` that:
1. Opens Git repositories safely and retrieves commit metadata (`author`, `timestamp`, `message`, `parents`).
2. Configures `Revwalk` with `simplify_first_parent()` and `Sort::TOPOLOGICAL | Sort::TIME` to guarantee deterministic first-parent iteration (Invariant I8).
3. Computes tree diffs between parent and child commits (or against an empty tree for root commits).
4. Enables rename and copy detection using `diff.find_similar()` so downstream function lineage and chunk generators know file provenance.
</context>
