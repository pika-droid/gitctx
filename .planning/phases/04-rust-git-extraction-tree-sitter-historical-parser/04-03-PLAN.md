<context>
Phase 4 Plan 03 completes the Phase 4 milestone by assembling the output artifacts required for hybrid indexing and retrieval in Phase 6.

Following decisions D-09 through D-16, this plan delivers:
1. **Identifier Delta Extractor:** Diffs tokens between added (`+`) and removed (`-`) diff lines, filtering language keywords (across all 8 supported languages) into structured `Added:` and `Removed:` identifier sets.
2. **Deterministic D4 Templater:** Formats natural-language pseudo-documents per function touch (and `<module>` touches for top-level changes) using the 6 canonical sections (Header, Sanitized Message, Added, Removed, Signature, Docstring), omitting empty sections cleanly.
3. **Defense-in-Depth Secret Redactor:** Executes prefix regex matching for known API tokens (GitHub, AWS, OpenAI, Slack, Private Keys, JWTs) and calculates Shannon entropy ($H \ge 4.5$) on candidate tokens $\ge 24$ chars, replacing them with typed semantic placeholders (`[REDACTED_SECRET: <type>]`) while exempting UUIDs and Git commit hashes.
</context>

<steps>
1. Create `crates/gitctx-core/src/redact/prefixes.rs` with pre-compiled regex patterns for:
   - GitHub tokens (`ghp_`, `gho_`, `ghu_`, `ghs_`, `ghr_`)
   - AWS access keys (`AKIA`, `ASIA`)
   - OpenAI keys (`sk-`, `sk-proj-`)
   - Slack tokens (`xoxb-`, `xoxp-`, `xoxa-`, `xoxr-`)
   - Private key headers (`-----BEGIN ... PRIVATE KEY-----`)
   - JWT bearer tokens (`eyJ...`)
2. Create `crates/gitctx-core/src/redact/entropy.rs` implementing:
   - Shannon entropy formula $H = -\sum p_i \log_2(p_i)$ over byte frequencies.
   - Token scanner finding candidate base64/hex tokens $\ge 24$ chars with threshold $\ge 4.5$ bits/char.
   - Exemptions for UUIDs (`[0-9a-fA-F]{8}-[0-9a-fA-F]{4}...`), Git commit SHAs (40-char/64-char hex), and test fixture hashes.
3. Create `SecretRedactor` in `crates/gitctx-core/src/redact/mod.rs` chaining prefix redaction, entropy filtering, and leakage sanitization (`sanitize_chunk_text`).
4. Create test suite `crates/gitctx-core/tests/redact_tests.rs` asserting:
   - Known token prefixes are replaced with `[REDACTED_SECRET: <type>]`.
   - High-entropy base64 tokens are replaced with `[REDACTED_SECRET: high_entropy_string]`.
   - Valid UUIDs and commit SHAs are left untouched.
</steps>
