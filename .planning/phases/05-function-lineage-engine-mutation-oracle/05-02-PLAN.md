<context>
Phase 5 Plan 02 builds the core function evolutionary identity resolution pipeline:
1. Multi-tier candidate generation:
   - Tier 1: Exact `(path, qualname)` match, gated by Decoy Rejection ($\text{Sim} \ge \tau_{\text{decoy}} = 0.25$) (D-08).
   - Tier 2: Same-file MinHash similarity $\ge \tau_{\text{same}} = 0.65$ (gated by token count $\ge 10$) (D-03, D-07).
   - Tier 3: Git rename/copy mapping (`find_similar`) with exact name or MinHash match (LINEAGE-02).
   - Tier 4: Scoped cross-file MinHash similarity $\ge \tau_{\text{cross}} = 0.75$, strictly limited to files touched in the commit with matching language (D-05, D-07).
   - Tier 5: Fallback new `LineageId` allocation.
2. Conflict resolution via greedy maximum-weight bipartite matching with deterministic secondary tie-breaking on `(score DESC, tier DESC, old_path ASC, old_qualname ASC, new_path ASC, new_qualname ASC)` to prevent dual claiming (D-06).
3. Lineage Derivation DAG: recording `LineageEdge { parent_lineage_id, child_lineage_id, commit_hash, kind: Split | Merge | Copy, similarity }` where dominant functions inherit existing lineages and secondary helpers record explicit provenance links (D-09, D-10, D-11).
4. Strict `UNIQUE(lineage_id, commit_hash)` invariant verification across all generated `FunctionTouch` records (D-11).
</context>

<threat_model>
| Threat | Mitigation |
| :--- | :--- |
| Combinatorial explosion during cross-file candidate generation | Strictly filter candidates to files touched in the same commit sharing the same programming language (D-05). |
| Duplicate lineage assignment per commit | Enforce `UNIQUE(lineage_id, commit_hash)` validation map in `LineageResolver` and reject duplicate assignments (D-11). |
| Decoy name hijacking (M8) | Apply $\tau_{\text{decoy}} = 0.25$ MinHash similarity check on exact name matches with structural AST changes (D-08). |
| Ambiguous tie breaks causing non-deterministic matching | Sort candidate pool with deterministic tie-breaking on `(score DESC, tier DESC, old_path ASC, old_qualname ASC, new_path ASC, new_qualname ASC)` (D-06, Invariant I2). |
</threat_model>
