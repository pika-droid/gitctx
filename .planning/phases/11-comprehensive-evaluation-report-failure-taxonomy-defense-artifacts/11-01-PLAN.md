# Phase 11-01: Evaluation Report Generator & Failure Taxonomy Implementation Plan

## Goal
Implement the automated evaluation report generator in `gitctx-eval` and `xtask`, reading actual Phase 3 ablation grid results, lineage calibration data, and corpus locks to generate `eval/REPORT.md` with a structured, Codanna-extrapolated failure taxonomy.

## Proposed Changes

### `gitctx-eval` (Evaluation Engine)

#### [NEW] `crates/gitctx-eval/src/report.rs`
- Implement report generator that reads:
  - `eval/results_matrix.json` (Phase 3 ablation grid metrics)
  - `eval/lineage_thresholds.json` (Phase 5 lineage calibration thresholds)
  - `eval/corpus.lock.toml` (Phase 2 pinned corpus)
  - `eval/manifest.json` (Ground truth manifest)
- Implement Codanna-extrapolated failure taxonomy with 10 pre-registered categories:
  1. `MISS_UNPARSED_BLOB`
  2. `MISS_LINEAGE_SPLIT_MERGE`
  3. `MISS_LOW_TEXT_SIMILARITY`
  4. `MISS_EMBEDDING_DRIFT`
  5. `MISS_LARGE_COMMIT_FILTER`
  6. `MISS_DOCSTRING_ONLY`
  7. `MISS_RENAME_CROSS_DIRECTORY`
  8. `MISS_IDENTIFIER_DISPERSION`
  9. `MISS_BM25_TERM_SATURATION`
  10. `MISS_EXCLUDED_PATH_OR_EXTENSION`
- Compute paired bootstrap confidence intervals (95% CI) and summary statistics.
- Format comprehensive markdown document (`eval/REPORT.md`).

#### [MODIFY] `crates/gitctx-eval/src/lib.rs`
- Export `report` module.

#### [MODIFY] `crates/gitctx-eval/src/main.rs`
- Add `Report` CLI subcommand with `--eval-dir` and `--output` options.
- Wire `run_report` execution handler.

### `xtask` (Development Automation)

#### [MODIFY] `xtask/src/main.rs`
- Add `Report` variant to `EvalSubcommands` enum.
- Route `cargo xtask eval report` to `gitctx-eval report`.

#### [MODIFY] `xtask/src/tasks/eval.rs`
- Implement `run_eval_report(eval_dir, output_path)` executing `cargo run -p gitctx-eval -- report`.

## Verification
- `cargo fmt --all -- --check`
- `cargo clippy --workspace --all-targets -- -D warnings`
- `cargo test --workspace`
- `cargo run -p gitctx-eval -- report --eval-dir eval --output eval/REPORT.md` produces valid `eval/REPORT.md`.
