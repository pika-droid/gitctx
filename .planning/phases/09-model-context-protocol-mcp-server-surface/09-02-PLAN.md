# Plan 09-02: `gitctx init` skill profile generator and MCP inspector test

## Goal
Provide a seamless integration for agentic AI workflows by generating `AGENTS.md` and MCP server configurations directly in the workspace, and ensure the MCP server works via integration testing.

## Implementation Details

### `gitctx init` Command (`MCP-05`)
- Added `Init` subcommand to `gitctx-cli/src/commands/mod.rs` and `init.rs`.
- When invoked, generates idempotent configuration files using `<!-- gitctx-begin -->` and `<!-- gitctx-end -->` markers.
- Writes `.agents/AGENTS.md` which includes:
  - `mcpServers` JSON block linking the `gitctx-mcp` binary.
  - A table of available tools and descriptions.
  - "Negative Guidance" to prevent the LLM from hallucinating usage (e.g., "Do NOT use `search_history` for current file content").
- Writes `.agents/skills/gitctx/SKILL.md` exposing a prompt injection "Skill" providing real-world query patterns.

### Inspector Integration Test
- Created `crates/gitctx-mcp/tests/inspector.rs`.
- Bootstraps a temporary Git repository and executes `cargo run --bin gitctx -- index`.
- Spawns `gitctx-mcp` dynamically via `std::process::Command`, mapping stdin/stdout/stderr pipes.
- Submits structured JSON-RPC requests (`initialize`, `tools/list`, and `tools/call`).
- Asserts that all 5 tools are recognized and the response envelope parses cleanly, proving that `stdout` isolation is maintained.

## Verification
- Run `gitctx init` on the actual `gitctx` repo to assert the `.agents` folder is accurately rendered (Confirmed).
- Run `cargo test -p gitctx-mcp --test inspector` to validate E2E stdio functionality (Confirmed).
