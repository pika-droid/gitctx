# Phase 7: Co-Change Graph & Impact Analysis Engine - Implementation Plan

## Goal
Implement a Co-Change Graph and Impact Analysis Engine (GRAPH-01 to GRAPH-05) that extracts temporal logical coupling from Git commits and computes impact risk scores.

## Proposed Changes

### `gitctx-query`

#### [NEW] `crates/gitctx-query/src/cochange/mod.rs`
Module root for the co-change analysis engine.

#### [NEW] `crates/gitctx-query/src/cochange/config.rs`
Configuration structs defining filtering thresholds (max commit files, bot patterns, decay half-life, min support).

#### [NEW] `crates/gitctx-query/src/cochange/decay.rs`
Exponential time-decay function weighting co-occurrences based on the time delta between commit and current HEAD.

#### [NEW] `crates/gitctx-query/src/cochange/extractor.rs`
Engine to scan commits, filter out bulk/bot commits, and extract canonically sorted pairwise co-change relationships.

#### [NEW] `crates/gitctx-query/src/cochange/metrics.rs`
Aggregator to compute Support, Directional Confidence (P(B|A) and P(A|B)), and Lift from extracted raw pairs.

#### [NEW] `crates/gitctx-query/src/cochange/graph.rs`
`petgraph` wrapper representing entities (files/functions) as nodes and metrics as edges, allowing top-K neighborhood queries.

#### [NEW] `crates/gitctx-query/src/cochange/impact.rs`
Impact risk scoring engine evaluating composite risk based on maximum confidence, follow-up fix ratio, and network complexity.

### `gitctx-index`

#### [MODIFY] `crates/gitctx-index/src/storage/mod.rs`
Add `query_commit_file_counts`, `query_commit_touched_paths`, `query_commit_touched_functions`, and `query_commits_touching_path`.

#### [MODIFY] `crates/gitctx-index/src/storage/schema.rs`
Add missing index `ix_touch_path` on `function_touches(path)` to prevent catastrophic full table scans during follow-up fix analysis.

### Dependencies
#### [MODIFY] `Cargo.toml`
Add `petgraph` dependency to the workspace and `gitctx-query` crates.

## Verification
- Create `cochange_test.rs` to verify full end-to-end extraction and graph building using an in-memory SQLite fixture.
- Create `cochange_maat_validation.rs` to validate confidence metrics strictly against Code Maat equations.
