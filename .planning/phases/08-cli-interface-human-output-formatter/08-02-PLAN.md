# Phase 8-02: Human-readable Terminal Formatters & Diagnostics

## Goal
Implement rich table rendering for human-readable output (timelines, diffs) that respects TTY environments, and build the `gitctx doctor` diagnostic tool.

## Proposed Changes

### `gitctx-cli` (Terminal Formatters)

#### [MODIFY] `crates/gitctx-cli/Cargo.toml`
- Add `comfy-table` (or `cli-table`), `anstyle` or `colored` for TTY styling.

#### [NEW] `crates/gitctx-cli/src/format/mod.rs`
- Table formatters for `evolution`, `search`, `impact` results.
- Honor `NO_COLOR` and non-TTY execution paths automatically.

#### [NEW] `crates/gitctx-cli/src/commands/doctor.rs`
- Implement `doctor` command logic to check SQLite index health, schema versions, and parse status.

## Verification
- Run `gitctx evolution <identifier> --format table` in a TTY environment.
- Run `gitctx doctor` to verify health reporting.
