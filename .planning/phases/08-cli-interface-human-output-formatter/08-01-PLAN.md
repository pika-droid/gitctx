# Phase 8-01: CLI Parser & JSON Envelope Implementation Plan

## Goal
Implement the core CLI command structure and argument validation with `clap`, and output typed, versioned JSON envelopes for programmatic usage.

## Proposed Changes

### `gitctx-cli` (CLI Core & Commands)

#### [MODIFY] `crates/gitctx-cli/Cargo.toml`
- Add `serde`, `serde_json`.

#### [MODIFY] `crates/gitctx-cli/src/main.rs`
- Expand `Commands` enum to include `Index`, `Search`, `Evolution`, `Show`, `Impact`, `Blame`, and `Doctor`.
- Add a global `--format` flag supporting `json` and `table` (default).

#### [NEW] `crates/gitctx-cli/src/commands/mod.rs`
- Module routing for all subcommands.

#### [NEW] `crates/gitctx-cli/src/envelope.rs`
- Implement typed `--json` output envelopes (`Response<T>` and `ErrorResponse`) with schema version `v1`.

## Verification
- Run `cargo test -p gitctx-cli`
- Verify `gitctx search --format json` produces valid JSON structure.
