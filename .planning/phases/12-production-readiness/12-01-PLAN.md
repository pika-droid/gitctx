## Changes Made

### 1. Cross-Platform ONNX Runtime Download (`xtask download-ort-runtime`)

**File:** `xtask/src/tasks/download_models.rs`

Added `run_download_ort_runtime()` function that:
- Detects current OS/architecture (Linux x86_64/aarch64, macOS x86_64/arm64, Windows x86_64)
- Downloads the matching ONNX Runtime v1.20.1 release archive from microsoft/onnxruntime GitHub Releases
- Extracts the shared library to `.ort/` in workspace root
- Prints `ORT_DYLIB_PATH=<path>` for CI consumers to capture via `$GITHUB_ENV`
- Uses `curl` with PowerShell `Invoke-WebRequest` fallback on Windows
- Caches downloads — skips if the library already exists

**File:** `xtask/src/main.rs`

Wired `DownloadOrtRuntime` subcommand: `cargo xtask download-ort-runtime`
