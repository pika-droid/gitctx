1. In `tests/fixtures/languages.rs`, define sample multi-language code snippets (per D-07) with standard functions, signatures, docstrings, and call sites:
   - Python: modules with functions, classes, methods, docstrings, and imports.
   - Rust: modules with functions, structs, impl blocks, and documentation comments.
   - JavaScript: modules with ES6 functions, classes, and exported methods.
2. In `tests/fixtures/mkrepo.rs`, create the `RepoBuilder` struct holding:
   - `temp_dir: Option<tempfile::TempDir>` (per D-08) for RAII cleanup, or explicit path if dumping.
   - `repo: git2::Repository`.
   - `commit_count: u64` tracking sequential commit index for deterministic time calculation.
   - `author_name: String` default `"gitctx-test"`.
   - `author_email: String` default `"test@gitctx.local"`.
   - `base_time: i64` default `1700000000`.
3. Implement core builder methods:
   - `new() -> Result<Self, git2::Error>`: creates repository in fresh `TempDir`.
   - `new_in(path: &Path) -> Result<Self, git2::Error>`: creates repository in target directory.
   - `write_file(path: &str, content: &str) -> Result<&mut Self, std::io::Error>`: writes or updates a file in the working tree.
   - `remove_file(path: &str) -> Result<&mut Self, std::io::Error>`: deletes a file from working tree.
   - `commit(message: &str) -> Result<git2::Oid, git2::Error>`: creates a commit with fixed signature (`author_name`, `author_email`, `base_time + commit_count * 60`, offset 0) per D-05.
   - `create_branch(name: &str) -> Result<(), git2::Error>`: creates and tracks a named branch.
   - `checkout_branch(name: &str) -> Result<(), git2::Error>`: switches working tree and HEAD to branch.
   - `merge(source_branch: &str, message: &str) -> Result<git2::Oid, git2::Error>`: merges source branch into current HEAD with two parent commits.
   - `squash_merge(source_branch: &str, message: &str) -> Result<git2::Oid, git2::Error>`: squashes source branch commits into single commit with single parent.
4. Expose `tests/fixtures/mod.rs` making `mkrepo` and `languages` accessible across test targets.

<threat_model>
## Trust Boundaries
- **TB-01 (Filesystem I/O)**: Creation and deletion of temporary fixture git repositories on the local filesystem.
- **TB-02 (CLI Parameter Ingestion)**: User-provided `--dump-dir` paths passed to `cargo xtask fixtures`.

## STRIDE Threat Register

| Threat ID | Threat Type | Component | Description | Mitigation Strategy |
|-----------|-------------|-----------|-------------|---------------------|
| `T-02-DET` | Repudiation / Integrity | `RepoBuilder` (`mkrepo.rs`) | System clock jitter or local git config leaking into commit metadata, causing non-deterministic fixture hashes. | Hardcode base timestamp (`1700000000`), sequential offset (`i * 60`), zero timezone offset, and fixed author signature per D-05. |
| `T-02-FS` | Denial of Service | `RepoBuilder` (`mkrepo.rs`) | Accumulation of leaked temporary repositories consuming disk space over extensive test suites. | Use RAII-managed `tempfile::TempDir` that automatically removes temporary directory tree when dropped per D-08. |
| `T-02-ESC` | Elevation of Privilege | Fixture Export (`fixtures.rs`) | Path traversal via unsanitized `--dump-dir` arguments overwriting arbitrary filesystem files. | Validate that `--dump-dir` path is created within project target directory or safe canonical path using `std::fs::create_dir_all`. |
</threat_model>
