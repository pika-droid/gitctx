<context>
Phase 6 Plan 04 combines SQLite, Tantivy BM25, and flat SIMD vectors into the unified hybrid query engine.
Key requirements:
1. Exact Symbol Priority: When a query contains a code identifier (e.g. `UserAuth::login` or `handle_request`), the fast-path directly queries the SQLite `qualified_name` index and injects hits at Rank-0 ($1 / (60 + 0)$), ensuring exact symbol lookups never miss (D-13).
2. RRF Fusion: Combines lexical BM25 and dense SIMD cosine rankings using standard Reciprocal Rank Fusion ($k=60$) (D-14).
3. Deduplication & Capping: Suppresses duplicate boilerplate hunks by chunk text hash and caps search results at max 3 touches per commit hash to prevent single massive refactors from monopolizing top-K results (D-15).
4. Lineage Chain Assembly: Queries complete evolutionary history by `lineage_id` in a single indexed query ordered by `topo_order ASC` (D-16, INDEX-06).
5. Citations: Every retrieved fact attaches non-null `Citation` metadata (`commit_hash`, `path`, `start_line`, `end_line`, `match_rule`, `match_confidence`) (D-16, INDEX-07, Invariant I4).
</context>
