<context>
Phase 6 Plan 03 implements the dense semantic retrieval vector store.
Key requirements:
1. Embedding Generation: `fastembed-rs` (pinned to 5.6.0) generates 384-dimensional dense embeddings completely offline using local ONNX Runtime CPU execution (D-09). Batch sizes of 128–256 optimize throughput; `ok` and `degraded` parse statuses are embedded while `failed` AST parses are skipped (D-12).
2. Binary Vector Format: Contiguous binary file `.gitctx/vectors.bin` with 16-byte header (`GVEC`, version, dim=384, count) memory-mapped via `memmap2` with SQLite `embeddings(touch_id, row_offset)` cross-reference (D-10).
3. High-Speed SIMD Cosine Search: Embeddings are normalized to unit L2 norm at write time ($\|\mathbf{v}\|_2 = 1.0$). At query time, unit query vector dot product over `&[f32]` is parallelized across CPU cores using `rayon`, scanning 100k vectors in <15ms without ANN graph build overhead (D-11).
4. Cross-Cutting Determinism: Validates double-indexing byte identity (INVAR-04 / Invariant I2) and incremental equivalence (INVAR-05 / Invariant I3).
</context>
