# Reference Repositories

This directory is intended for holding cloned reference codebases and tools (e.g., `codanna`, `tree-sitter-python`, `code-maat`, etc.) to consult, reuse, and adapt patterns without reinventing the wheel.

> **Note:** Cloned repositories in this directory are git-ignored by the root `.gitignore` to keep the main `gitctx` working tree clean.
